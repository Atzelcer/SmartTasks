## ✨ Características

### 🎨 **Diseño**
- **Tema claro y oscuro**: Cambia entre modos según tu preferencia
- **Animaciones suaves**: Transiciones fluidas en la interfaz
- **Fácil de usar**: Interfaz simple y clara

### 📋 **Tareas**
- ✅ Crear, editar y eliminar tareas
- 🎯 Prioridades: Alta, Media, Baja
- 📅 Fechas de creación y completado
- 🔍 Filtrar tareas por estado
- 💾 Se guardan automáticamente

### 🏗️ **Tecnología**
- **MVVM**: Código organizado
- **Jetpack Compose**: Interfaz moderna
- **Room Database**: Base de datos local
- **Navigation**: Navegación entre pantallas

## 📦 Instalación

1. **Clona el proyecto**
```bash
git clone https://github.com/atzelcer/SmartTasks.git
cd SmartTasks
```

2. **Abre en Android Studio**
3. **Ejecuta la app**
